# MultiPost AI - Multi-Platform Social Media Automation

A production-ready SaaS website for MultiPost AI - the tool that lets you write once and publish to 10+ platforms automatically.

## 🚀 Quick Start

This is a static website that works on any hosting. To deploy:

1. **GitHub Pages** (Recommended):
   - Already deployed! Just enable Pages in repository settings
   - Live at: `your-username.github.io/multipost-ai`

2. **Custom Domain**:
   - Add CNAME file with your domain
   - Configure DNS to point to GitHub Pages
   - Website goes live on your domain

## 📁 Files

- `index.html` - Main production website (all-in-one file, 195 KB)

## 🔧 Customization

Edit `index.html` to change:
- Colors: Find `:root {` section, change `--primary` color
- Text: Find and replace "MultiPost AI" with your product name
- Phone: Replace "+91 84460 00784" with your phone
- Domain: Replace "vdldigital.com" with your domain
- Pricing: Update the price values
